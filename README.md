# Bedrock

Bedrock traces container workloads and removes unused files to create a distroless equivalent. It generates SBOMs, matches vulnerabilities, prunes, and signs the output.

## Project Status

Bedrock is currently in active development (Phase 0/1). 
The core OCI and filesystem logic is partially implemented. Advanced features like reachability tracing, pruning, vulnerability scanning, and signing are currently stubs and are not yet functional.

Please refer to `BEDROCK_SPEC.md` for the roadmap.
